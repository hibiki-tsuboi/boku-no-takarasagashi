# ぼくの宝探し

家の中や身近な場所を、誰かのための小さな冒険に変えるiPhoneアプリです。

## このアプリを作ったきっかけ

子どもの頃、従兄弟が宝探しゲームを作ってくれました。最初に渡された紙のヒントを読み、タンスの中、庭、近所の用水路などを探して、宝に見立てたBB弾を見つける遊びです。

宝が複数あるときは、1つ見つけるたびに次のヒントが現れ、最後の宝へたどり着くとゲームクリア。そのときの「自分のために冒険を用意してもらった」記憶が、このアプリの原点です。

現在のアプリでは、そのワクワク感を残しながら、道路・水辺・高所などを避けて安全に遊べる体験を目指しています。

## コンセプト

「しかける人」が宝とヒントを用意し、1台のiPhoneを「さがす人」へ渡して遊びます。親子だけでなく、きょうだい、親戚、友達同士でも使える設計です。

1. 宝探しのタイトルと開始・クリアメッセージを入力する
2. 宝を見つける順番に、最大10個のヒントを登録する
3. 宝ごとに発見方法を選び、実物の宝を隠す
4. 安全確認後、iPhoneをさがす人へ渡す
5. 宝を見つけると次のヒントが開き、最後の宝でクリア

## 発見方法

| 方法 | 準備 | 遊び方 |
| --- | --- | --- |
| みつけた！ | 不要 | 宝を発見したら自己申告ボタンを押す |
| 合言葉 | 紙とペン | 宝と一緒に置いた言葉を入力する |
| QRコード | 印刷物または別端末 | アプリが生成した画像を隠し、カメラで読み取る |
| NFCタグ | 書き込み可能なNDEFタグ | 作成時にタグへ書き込み、発見時にiPhoneを近づける |

QRコードとNFCタグには宝ごとに異なる識別子を保存します。別の宝を先に読み取ってもクリア扱いにはなりません。

## 複製と共有

宝探しカードの保護者メニューから、PIN確認後に複製または共有できます。共有ファイルはAirDrop、メッセージ、ファイルなどで送信でき、受け取った側はホーム画面右上の「＋」から読み込みます。

共有ファイルにはヒント、合言葉、写真、発見方法が含まれますが、保護者PIN、進行状況、冒険履歴は含まれません。読み込み時に新しいPINを設定し、QRコードとNFCタグは新しい識別子で準備し直します。

## 現在実装されている機能

- 宝探しの作成・編集・並べ替え
- 既存の宝探しを再利用できる複製
- 写真を含む宝探し共有ファイルの書き出し・読み込み
- 「おうち探検」「雨の日」「おたんじょうび」テンプレートからの作成
- 宝ごとの道具準備、読み取りテスト、設置確認ができる準備モード
- カメラ撮影または写真ライブラリから追加できる写真ヒント
- 子どもが必要なときだけ開ける、宝ごとのおたすけヒント
- 通常ヒント・おたすけヒントの日本語音声読み上げ
- SwiftDataによる端末内保存と途中再開
- クリア日時、宝の数、おたすけヒント使用数を残す冒険履歴
- 記念写真、遊んだ人、ひとことを保存・編集・共有できる思い出アルバム
- 4桁の保護者PINによるプレイ画面のロック
- QRコードの生成、共有、印刷、カメラスキャン
- NFCタグへのNDEF書き込みと読み取り
- 発見・クリア時の効果音、触覚フィードバック、クリア演出
- プレイ前の安全確認
- 既存データを維持したモデル移行

アカウント、サーバー、位置情報は使用せず、宝探しと写真を含む思い出データは端末内に保存します。思い出は、利用者が共有ボタンを押したときだけiOSの共有画面へ渡されます。

## 技術構成

- SwiftUI：画面とアニメーション
- SwiftData：宝探し、ステージ、進行状況の永続化
- PhotosUI / UIKit：写真ヒントの選択と撮影
- AVFoundation：ヒントの音声読み上げと効果音
- Foundation / Codable：宝探し共有ファイルの生成と検証
- VisionKit / Core Image：QRコードの読み取りと生成
- Core NFC：NDEFタグの読み書き
- CryptoKit：保護者PINのハッシュ化

主な実装は `ContentView.swift`、`HuntEditorView.swift`、`PlaySessionView.swift`、`TreasureModels.swift` にあります。写真、音声、テンプレート、履歴、共有はそれぞれ専用ファイルに分離し、QRとNFCも `QRCodeViews.swift`、`NFCService.swift` にまとめています。

## 開発と実機確認

必要環境はXcode 26.6以降、iOS 26.5以降です。

```sh
open BokuNoTakarasagashi.xcodeproj
```

シミュレータ向けのビルド確認：

```sh
xcodebuild \
  -project BokuNoTakarasagashi.xcodeproj \
  -scheme BokuNoTakarasagashi \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  build
```

実機で動かす場合は、XcodeのSigning & Capabilitiesで自分のDevelopment Teamを選択してください。QRコードにはカメラ対応端末、NFCには対応iPhoneと書き込み可能なNDEFタグが必要です。QRの初回利用時にはカメラの許可画面が、NFC利用時にはシステムの読み取り画面が表示されます。

## 安全について

宝は道路、駐車場、水辺、高所、立入禁止場所へ隠さないでください。屋外では大人が付き添い、私有地や周囲の人へ配慮して遊んでください。
